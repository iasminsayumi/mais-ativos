# mais-ativos

O Mais Ativos é uma plataforma web desenvolvida com o objetivo de promover
saúde, bem-estar e hábitos saudáveis para pessoas idosas.

A plataforma apresenta conteúdos relacionados a exercícios, alimentação,
hidratação, sono, memória, mente, relaxamento e outros cuidados importantes
para o bem-estar.

## Tecnologias utilizadas

- HTML
- CSS

## Acesso ao site

O site está disponível através do Netlify.
